# Data Visualization Practice Portfolio

**Target Role:** Data Analyst / Data Scientist  
**Status:** Ongoing / Continuous Learning

## Overview
This repository is an active, growing portfolio of my foundational practice in Data Visualization. As I progress in my journey toward becoming a Data Scientist, I am using this space to document how I transform raw data into clear, actionable, and interactive visual insights using Python's leading plotting libraries.

## Tools & Libraries Explored
This repository currently contains three distinct Jupyter Notebooks, each focusing on a specific visualization library:

1. **`Matplotlib.ipynb`**: Demonstrates core plotting mechanics, including basic line charts, bar graphs, object-oriented plotting, and subplot grid arrangements.
2. **`saeborn.ipynb`**: Focuses on statistical data visualization, utilizing datasets to create distribution plots, box plots, and heatmaps for deeper analytical context.
3. **`plotly.ipynb`**: Explores interactive plotting capabilities for dynamic dashboards and exploratory data analysis (EDA).

## Key Learnings & Current Focus
* Understanding the object-oriented approach in Matplotlib.
* Mapping statistical relationships, analyzing distributions, and handling outliers with Seaborn.
* Enhancing user engagement with Plotly's interactive graphics.
* Continuously improving best practices for chart formatting, color palettes, and data storytelling.
